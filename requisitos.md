## Definição de Requisitos do Sistema Login

### Requisitos Funcionais

- RF01: Entrada de credenciais: o software deve receber dados de autenticação enviados pelo cliente. Ex.: Identificador de usuário + senha; ou e-mail + senha;
- RF02: Validação das credenciais: o sistema deve realizar a verificação da existência do usuário no repositório de dados;
- RF03: Comparação da credenciais: o software deve comparar a credencial informada pelo usuário com a credencial registrada;
- RF04: Decisão de autenticação: o sistema deve decidir se o usuário está ou não autenticado. O usuário está autenticado quando as suas credenciais são válidas; ele não está autenticado quando as credenciais são inválidas ou o usuário é inexistente;
